# Bit a Bit

Um jogo incremental no navegador: comece com um bit e descubra o que existe depois do último byte.

**Jogar:** https://akanyane.github.io/bit-a-bit/

Tudo roda num único `index.html`, sem dependências. O progresso fica salvo no navegador.
